# 3. Decoded UEFI Setup Variable Section

The file Fujitsu-Futro-S940-Setup-V50013-R1140.txt contains the extracted and decoded setup variable section of UEFI version V5.0.0.13 R1.14.0 of the D3543-A1x board, which is used in the Futro S940. Please keep in mind that different versions may have differerent variables before you try to change any variable. Failure to do so might render your board unbootable
