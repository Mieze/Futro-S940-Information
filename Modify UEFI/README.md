## Modifying the Futro S940's UEFI
### 5.1 Required tools
- A computer running Linux x86_64 or Windows 10
- The [Intel CSTXE System Tools v4 for Gemini Lake systems](https://comsystem-tlt.ru/ME_TXE/Intel%20CSTXE%20System%20Tools%20v4%20r6.rar).
- A flash programming tool, e.g. a cheap CH341 based programmer with an 1.8V adapter (you would fry your flash chip without) and a clip to connect a flash chip in a SOP8 package [like this](https://github.com/Mieze/Futro-S940-Information/blob/main/images/flash_programmer.png).
- The document [System Tools for Gemini Lake: Intel® Trusted Execution Environment 4.0](https://www.google.com/url?sa=t&source=web&rct=j&opi=89978449&url=https://www.corus.pro/pilotes/AX25/J4125/Gemini%2520Lake_GK1_Driver/GK1/intel(r)_trusted_execution_engine_driver_4.0.0.1242/GLK%2520TXE%25204.0.0.1242%2520B0%2520RS3%2520PV%2520Release/Tools/GLK_System_Tools_User_Guide_TXE%25204_0.pdf&ved=2ahUKEwjooaaX-raVAxVO_rsIHZzvI5UQFnoECBgQAQ&usg=AOvVaw3fokfHW1Z6SKJpFnELovdX).
- The document [Apollo Lake SoC SPI and Signed Master Image Profile (SMIP) Programming Guide](https://www.google.com/url?sa=t&source=web&rct=j&opi=89978449&url=https://www.portwell.eu/index.php%3FeID%3DdumpFile%26t%3Df%26f%3D10255%26token%3D8eaa975436a21f2bb8f0bf3095a95c1ddee9e6e0%26download%3D&ved=2ahUKEwjP1a-W-7aVAxV78bsIHQFqMTwQFnoECBcQAQ&usg=AOvVaw3P_lQklb187qzKIXzbOkNI). Although this document doesn't apply to the Gemini Lake SoC of the Futro S940, it gives you a basic understanding how to modify the SoC's hardware configuration.
