# Modifying the Futro S940's UEFI
## 1. Required tools
- A computer running Linux x86_64 or Windows 10
- The Intel CSTXE System Tools v4 for Gemini Lake system, which can be downloaded from this [website](https://comsystem-tlt.ru/ME_TXE/Intel%20CSTXE%20System%20Tools%20v4%20r6.rar).
- A flash programming tool, e.g. a cheap CH341 based programmer with an 1.8V adapter (you would fry your flash chip without) and a clip to connect a fash chip in a SOP8 package [like this](https://github.com/Mieze/Futro-S940-Information/blob/main/images/flash_programmer.png).
- The [System Tools for Gemini Lake: Intel® Trusted Execution Environment 4.0](https://www.google.com/url?sa=t&source=web&rct=j&opi=89978449&url=https://www.corus.pro/pilotes/AX25/J4125/Gemini%2520Lake_GK1_Driver/GK1/intel(r)_trusted_execution_engine_driver_4.0.0.1242/GLK%2520TXE%25204.0.0.1242%2520B0%2520RS3%2520PV%2520Release/Tools/GLK_System_Tools_User_Guide_TXE%25204_0.pdf&ved=2ahUKEwjooaaX-raVAxVO_rsIHZzvI5UQFnoECBgQAQ&usg=AOvVaw3fokfHW1Z6SKJpFnELovdX).
